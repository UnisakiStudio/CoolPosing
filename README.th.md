# Cool Posing Tool

ซอร์สโค้ดและทรัพยากรของ Cool Posing Tool ที่จำหน่ายบน BOOTH

## วิธีใช้และประวัติการอัปเดต

- [README: การติดตั้ง อัปเดต และตั้งค่า](Packages/jp.unisakistudio.coolposing/Documentation~/Localization/th/README.md)
- [ประวัติการอัปเดต](Packages/jp.unisakistudio.coolposing/Documentation~/Localization/th/CHANGELOG.md)
- [หน้าสินค้า BOOTH](https://yunisaki.booth.pm/items/8797334)

ตรวจสอบเวอร์ชันที่ติดตั้งได้ที่ด้านบนของ Inspector เมื่อเลือกเครื่องมือท่าใน Unity วิธีใช้รวบรวมไว้ใน README ภายในแพ็กเกจ

## ที่เก็บนี้และข้อกำหนดการใช้งาน

ซอร์สโค้ดและทรัพยากรในที่เก็บนี้ไม่ใช่โอเพนซอร์ส การใช้งานต้องซื้อสินค้าบน BOOTH และยอมรับข้อกำหนดการใช้งาน
