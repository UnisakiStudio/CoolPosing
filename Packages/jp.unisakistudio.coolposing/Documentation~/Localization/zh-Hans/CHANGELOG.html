更新记录

[1.2.0] - 尚未发布

新增

  • Inspector、编辑操作、安装对话框、标准姿势名和生成的VRChat菜单现支持30种显示语言。
  • 统一了Inspector和游戏内菜单的语言选择。初始使用计算机语言，同一OS用户的其他项目也会使用最后的选择。
  • 支持以所选语言打开README、更新记录和离线使用说明。
  • 依照现有术语，补齐了128个标准姿势的显示名和各功能说明。

兼容性

  • 保留虚拟形象的现有设置、自定义名称、资源引用、参数标识符和许可证保存方式。

[1.1.0] - 2026-11-07

  • 收录的50种姿势中，43种可根据虚拟形象体型，通过IK自动调整手脚。其余7种使用原有的按姿势调整。
  • 拍照模式可调整虚拟形象的位置和朝向，也可选择同步位置、朝向，以及拍照时显示自己的头部。
  • “地面高度”可上下移动整个身体，最大距离为3m，可与“脚部高度”分别使用。
  • 新增呼吸动作、关闭默认待机摇摆及减轻头部朝向造成姿势变形的设置。
  • 可在Inspector查看启用功能和参数用量，并支持姿势搜索、批量添加、排序及Scene简易预览。
  • 加快桌面模式中站立、半蹲和坐姿的切换。
  • 改善设置变化后的预构建警告、Inspector滚动负担及清理生成资源时的长时间停顿。
  • 支持Unisaki Posing System 3.1.0。
  • 未收录附带姿势的翻身动作。

[1.1.0-beta.2] - 公开测试版（2026-11-05）

  • 收录的50种姿势中，43种已设置手脚自动调整（IK），其余7种使用原有的按姿势调整。
  • 支持共用软件包3.1.0-beta.2。此次附带姿势未收录翻身动作。

[1.1.0-beta.1] - 公开测试版（2026-11-04）

  • 支持Unisaki Posing System 3.1.0-beta.1。
  • 将桌面模式的普通姿势切换改为1次求值方式。普通构建和预构建均启用，VR及特殊条件下保留原有流程。
  • 将alpha.3及更早版本的预构建识别为需要更新。
  • 拍照期间改变地面高度时保持视点，并在结束拍照后恢复至最新地面高度。
  • 纳入截至alpha.3对自动导入、导入动作调整及生成Controller管理的改进。

[1.1.0-alpha.1] - 发布前

新增

  • 新增翻身及各姿势的对应动画设置。
  • 新增呼吸、翻身、地面高度、拍照模式、距离、朝向、结束拍照的专用菜单图标。
  • 新增可调整向前移动和旋转的拍照模式。
  • 新增拍照模式同步设置。仅本地显示为0 bit，同步时为16 bit。
  • 新增拍照模式中保持自身虚拟形象头部可见的设置。
  • 新增可抬高包含头部的整个身体的“地面高度”。
  • 新增呼吸动作、强度设置和游戏内开关菜单。
  • 新增关闭VRChat默认站立摇摆的设置。
  • 新增减轻头部朝向不同造成姿势变形的设置。
  • 新增防止膝盖反折及最小弯曲角度设置。
  • 新增各功能开关和ExpressionParameters用量显示。
  • 新增Scene简易预览、姿势搜索、批量添加及指定目标顺序。
  • 新增Inspector内的更新记录显示。

更改

  • 将Inspector整理为“功能”“姿势”“头像设置”3个选项卡。
  • 整理呼吸详情、自定义动作导入及预设的设置位置。
  • 减少脚部高度调整生成动画的重复。
  • 为姿势图片更新添加确认对话框，并将警告设置集中到“检查设置”中。
  • 取消8bit版本的新建菜单，统一为普通Prefab的功能选择。保留现有引用。
  • 支持Unisaki Posing System 3.1.0-alpha.1。将VRChat Avatars SDK的最低版本改为3.10.4。

修复

  • 修复了姿势名输入转移到其他姿势，以及排序时详情关闭的问题。
  • 修复了预览重叠、放置位置偏移及某些虚拟形象报错的问题。
  • 修复了设置变化后警告和预构建状态的更新，以及部分构建错误。
