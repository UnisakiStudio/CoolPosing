சேர்த்தவை

  • புரளலும் ஒவ்வொரு போஸுக்கான அசைவூட்ட அமைப்பும் சேர்க்கப்பட்டன.
  • மூச்சு, புரளல், தரை உயரம், புகைப்பட முறை, தூரம், திசை, புகைப்படம் முடித்தல் ஆகியவற்றுக்குத் தனிப் பட்டிச் சின்னங்கள் சேர்க்கப்பட்டன.
  • முன்னோக்கி நகர்வு மற்றும் சுழற்சிக்கான புகைப்பட முறை சேர்க்கப்பட்டது.
  • புகைப்பட முறை ஒத்திசைவு அமைப்பு சேர்க்கப்பட்டது. உள்ளூரில் மட்டும் 0 bit; ஒத்திசைவுக்கு 16 bit.
  • புகைப்பட முறையில் உங்கள் அவதாரின் தலையை மறைக்காத அமைப்பு சேர்க்கப்பட்டது.
  • தலை உட்பட முழு உடலை உயர்த்தும் «தரை உயரம்» சேர்க்கப்பட்டது.
  • மூச்சு அசைவு, வலிமை அமைப்புகள், விளையாட்டில் இயக்க/நிறுத்தப் பட்டி சேர்க்கப்பட்டன.
  • VRChat இயல்புநிலை அசைவை நிறுத்தும் அமைப்பு சேர்க்கப்பட்டது.
  • தலைச் சுழற்சியால் போஸ் சிதைவதைக் குறைக்கும் அமைப்பு சேர்க்கப்பட்டது.
  • முழங்கால் பின்னோக்கி மடங்குவதைத் தடுத்தலும் குறைந்தபட்ச மடக்கக் கோண அமைப்பும் சேர்க்கப்பட்டன.
  • ஒவ்வொரு வசதியின் இயக்கம்/நிறுத்தமும் ExpressionParameters பயன்பாட்டுக் காட்சியும் சேர்க்கப்பட்டன.
  • எளிய Scene முன்னோட்டம், போஸ் தேடல், கூட்டுச் சேர்த்தல், இலக்கு வரிசைத் தேர்வு சேர்க்கப்பட்டன.
  • Inspector-க்குள் மாற்றப் பதிவுக் காட்சி சேர்க்கப்பட்டது.

மாற்றங்கள்

  • Inspector «வசதிகள்», «போஸ்கள்», «அவதார் அமைவு» என மூன்று தாவல்களாக ஒழுங்குபடுத்தப்பட்டது.
  • மூச்சு விவரங்கள், தனிப்பயன் இயக்க இறக்குமதி, முன்னமைவு அமைவிடங்கள் ஒழுங்குபடுத்தப்பட்டன.
  • பாத உயரத் திருத்தத்தில் உருவாக்கும் அசைவூட்ட நகல்கள் குறைக்கப்பட்டன.
  • போஸ் படப் புதுப்பிப்பில் உறுதிப்படுத்தல் உரையாடல் சேர்க்கப்பட்டு எச்சரிக்கை அமைப்புகள் «அமைப்புகளைச் சரிபார்»-க்குள் ஒருங்கிணைக்கப்பட்டன.
  • புதிய 8bit சேர்த்தல் பட்டி நீக்கப்பட்டு வழக்கமான Prefab வசதித் தேர்வில் ஒருங்கிணைக்கப்பட்டது. தற்போதைய குறிப்புகள் பாதுகாக்கப்படும்.
  • Unisaki Posing System 3.1.0-alpha.1 ஆதரவு சேர்க்கப்பட்டது. குறைந்தபட்ச VRChat Avatars SDK பதிப்பு 3.10.4 ஆக மாற்றப்பட்டது.
