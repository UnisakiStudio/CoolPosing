# Cool Posing Tool

這是一款面向VRChat的姿勢固定工具，即使使用3點追蹤或桌面模式，也能切換為帥氣姿勢。共收錄50種姿勢：站立11種、半蹲9種、坐姿14種、仰臥9種、俯臥7種。

本README面向開發中的v1.2.0。正式發佈日期尚未確定。已安裝的版本可在Inspector頂部查看。

## 顯示語言與離線文件

在Inspector最上方的“Language / 言語”中選擇顯示語言。同一項選擇會同時套用於Inspector和產生的VRChat選單。要更改遊戲內的顯示語言，請重新上傳虛擬化身。

未選擇語言時，使用電腦的語言；不支援該語言時使用英語。支援Windows、macOS和Linux。最後選擇的語言儲存在EditorPrefs中，同一臺電腦上同一個OS使用者的其他專案也會使用此設定。已明確儲存在虛擬化身中的語言選擇會予以保留。語言設定不會同步到其他電腦。授權的儲存方式不變。

可通過隨附的[語言清單](../index.html)選擇README、更新紀錄和使用說明。Inspector中的“使用說明”和“更新紀錄”也會遵循所選語言。原始使用條款和參考譯文仍按原有方式另行提供。

## 主要功能

- 手腳自動調整（IK）：43種姿勢可根據虛擬化身體型調整手腳的位置和朝向。

- 拍照模式：可將虛擬化身向前移動，最遠達3m，並調整朝向。僅自己的畫面使用時為0 bit；向其他人同步位置和朝向時為16 bit。
- 拍照時的頭部顯示：可僅在拍照模式中，防止靠近自己的虛擬化身頭部被隱藏。
- 地面高度：可將包含頭部的整個身體上下移動，最遠3m。可與保持頭部位置、移動腳部一側的“腳部高度”分別使用。
- 翻身：可用於自行設定對應動作的姿勢。附帶姿勢未收錄翻身動作。
- 呼吸：可為胸部等新增呼吸動作。各姿勢分類可選擇“無、弱、中、強、急、自訂”。
- 關閉VRChat預設站立搖擺：抑制預設待機搖擺，同時保留姿勢工具的呼吸和其他自訂動作。
- 減輕頭部旋轉造成的姿勢變形：解除頸部固定時，減輕頭部朝向與原始姿勢不同造成的姿勢變形。
- 功能選擇：僅新增所需遊戲內選單，並在Inspector中查看ExpressionParameters用量。
- 姿勢搜尋、批次加入與排序：支援跨分類搜尋、匯入多個片段及指定目標順序。
- Scene簡易預覽：通過姿勢清單的“預覽”即可原地查看姿勢。

- 新功能選單圖示：為呼吸、翻身、地面高度、拍照模式等提供與商品現有圖示風格相配的專用圖片。

### 設定翻身

在所需躺姿的“詳情”中啟用“啟用翻身”，並在“翻身側向姿勢”中指定動畫。啟用後無法使用一般MotionTime設定。另請啟用“功能 > 選單功能 > 翻身”再上傳，在VRChat中選擇支援的姿勢和“翻身”。使用時請解除頸部固定。

此次附帶的姿勢未收錄用於翻身的動作，請為所需姿勢設定對應動畫。

## 安裝方法

1. 從購買商品的商店頁面下載檔案。
2. 將隨附的“カッコいいポーズツール.unitypackage”匯入Unity，註冊授權和套件來源。
3. 在VCC或ALCOM中，向所用Unity專案加入Cool Posing Tool和Modular Avatar。共用的Unisaki Posing System和NDMF也會作為相依套件安裝。
4. 在Hierarchy中右鍵按一下目標虛擬化身，選擇“Unisaki Studio > 加入Cool Posing”。
5. 選取新增到虛擬化身內的“カッコいいポーズ”，在Inspector中設定所需功能和姿勢。
6. 按一般流程上傳虛擬化身。

所需環境為Unity 2022.3、VRChat Avatars SDK 3.10.4或更高版本、Modular Avatar 1.15.1或更高版本的1.x系列，以及NDMF 1.14.0或更高版本的1.x系列。請通過VCC或ALCOM一同更新所需套件。

## 從舊版本更新

請將本商品和Unisaki Posing System一同更新。已放置工具的設定會繼承。請在Inspector確認啟用功能和ExpressionParameters用量；如果使用過預先建置，重新上傳前請按一下“更新預先建置”。

從v1.1.0起，新增物件統一使用一般“カッコいいポーズ”Prefab。在“功能”中關閉不需要的項目後，僅使用姿勢選擇的最小設定為8 bit。姿勢數量較多時，姿勢選擇可能需要額外的bit。

為保留現有虛擬化身和預設的參照，舊8bit版Prefab仍儲存在“Editor/Legacy”中。無需刪除或替換現有Prefab。Unity新建選單不會顯示8bit版本。

## 設定位置

| 頁籤 | 可進行的操作 |
| --- | --- |
| 功能 | 新增遊戲內選單、便利功能、呼吸設定、圖示圖片和ExpressionParameters用量確認 |
| 姿勢 | 選擇使用的姿勢、詳細設定、搜尋、批次加入、順序調整、預覽、動畫調整 |
| 虛擬化身設定 | 虛擬化身專屬修正、膝部修正、匯入原始姿勢或自訂動作、更改預設 |

按一下“開啟設定”，即可在該項目下方展開詳細設定。呼吸通過“功能 > 便利功能 > 啟用呼吸動畫”設定。

“使用虛擬化身原有的站立、蹲下和俯臥姿勢”是自動匯入虛擬化身原始姿勢的功能。如需使用自己準備的動作，請通過單獨的“開啟匯入設定”，為站立、蹲下（Crouching）、俯臥（Prone）等各類型分別指定。

預設位於“虛擬化身設定”的最下方。“套用此預設”會替換當前姿勢設定，因此切換前請儲存已有調整。

### 各功能用量

- 呼吸動作使用0 bit。只有使用可在遊戲內暫停和恢復的“選單功能 > 呼吸”時，開關同步才使用1 bit。
- 拍照模式僅在自己畫面中顯示時為0 bit。選擇“便利功能 > 同步拍照模式”時使用16 bit。“拍照模式中保持頭部可見”為0 bit。
- “腳部高度”“地面高度”各使用8 bit。地面高度離開中央時，整個身體會上下移動，恢復至50%附近時結束。
- “翻身”單獨使用為10 bit。由於與“減輕頭部旋轉造成的姿勢變形”共用1 bit，兩者同時使用時合計仍為10 bit。
- “左右鏡像”“停用手勢”各使用1 bit。

Inspector的合計值僅涵蓋安裝在虛擬化身中的姿勢工具，不包括服裝等其他功能元件。即使並用多個姿勢工具，共用設定也不會重複計數。

### 預覽與姿勢編輯

通過“姿勢”中各姿勢的“預覽”，可在Scene顯示姿勢。需要細調時，開啟“動畫調整”，一邊確認姿勢一邊調整並儲存。

簡易預覽不會執行MA或NDMF的建置處理。建置時整合的服裝、地面位置修正等，也請在上傳前的建置結果中確認。

左側的放大鏡頁籤可搜尋姿勢名。可在“詳情”的“順序”中選擇目標位置，也可通過上下按鈕排序。多個動畫可拖放到新增區域，或通過“匯入Project中選擇的片段”批次加入。

“更新姿勢縮圖”會在確認對話框後產生圖片。“產生姿勢圖示”可讓遊戲內選單中的姿勢更容易辨認，但產生圖片會增加建置時間。如需降低容量，請選擇“減少圖示容量”。面向Android時不會產生姿勢圖示。

## 遊戲內基本操作

- 在Expressions選單中選擇各分類的姿勢。VR模式會根據頭部高度切換站立、半蹲、坐姿和躺姿。
- 躺姿會根據面部朝向切換仰臥和俯臥。兩者都已選擇時，也可通過跳躍切換，並可在“功能 → 便利功能 → 跳躍切換躺姿”中關閉。分類切換高度可通過設定選單中的閾值調整。
- 桌面模式使用C鍵、Z鍵切換姿勢。如果按Z鍵未進入躺姿，請在設定選單中提高“躺姿高度閾值”。
- 啟用“停用手勢”後，會使用姿勢中設定的手型，代替控制器輸入的手指形狀。
- “腳部高度”保持頭部位置、調整腳部一側。“地面高度”上下移動包含頭部的整個身體。它們在設定選單中按此順序排列。
- 在“拍照模式”中使用“距離”向前移動後，虛擬化身會朝向自己。通過“朝向”旋轉，並在需要時啟用“固定雙腳”。“結束拍照”會恢復距離、朝向並解除雙腳固定。
- “呼吸”僅在已啟用呼吸動作時可用。強度在Unity中設定，遊戲內僅切換開關。

## 預先建置與警告

“更新預先建置”通過重複使用產生資料，加快虛擬化身建置。即使不使用預先建置，一般建置時也會產生所需資料。

更改設定後，會通過Inspector頂部的“檢查設定”和Hierarchy標記提示更新。“警告顯示設定”位於“檢查設定”區域內。隱藏提示並不意味著設定問題已解決，或產生資料已更新。

## 使用注意事項

- 不支援全身追蹤期間的姿勢固定。
- 根據體型、服裝和虛擬化身修改內容，可能需要額外調整。
- 可能無法與特殊Base層或其他姿勢切換元件按預期整合。固定功能不正常時，也請檢查“虛擬化身設定 > 與其他工具整合追蹤鎖定”。
- 拍照模式的移動、旋轉及地面高度，會修正工具姿勢以及未選擇工具姿勢時的預設和自訂動作。請在VRChat用戶端確認最終視點及動作替換後的表現。
- “關閉VRChat預設站立搖擺”針對預設待機動作，並非停止一切原因引起的搖擺。
